Built on OpenMRS

The platform under the platforms.

You can build your own distribution of OpenMRS, or start from one that already exists. National systems in Kenya, Uganda and Cambodia run on OpenMRS 3; distributions like Ozone HIS, Bahmni and PIH EMR package it with their own content and support. Each adds its own layer. All of them share one core, and what they contribute back makes it stronger for everyone.

04 · Build your own

Every one of these started from the same place.

The Reference Application is the starting point. A distribution is the Reference Application plus your choices: which modules and apps, which forms and concepts, which integrations, whose logo. Those choices live in configuration and content, and in modules you write, not in a copy of the core.

Build your own distribution How extension works
  1. 01Start from the Reference ApplicationFork the distro repo, not openmrs-core. It's a compose file and a list of modules.
  2. 02Add your contentForms, concepts, locations and programmes as a content package you version.
  3. 03Add your modules and appsIntegrations and workflows the core doesn't have. Keep them private or publish them.
  4. 04Track upstreamPin a Reference Application version; move when the next one is out. Fixes you make to shared code go upstream.
  5. 05Name it, and say what it's built on"Built on OpenMRS" is how the ecosystem credits each other. Trademark rules are on Security & trust.
