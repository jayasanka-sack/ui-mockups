DOCKER

RECOMMENDED

The Reference Application, in minutes

Four containers: database, backend, frontend and gateway. The same images run on a laptop and on a national server.

$ git clone https://github.com/openmrs/openmrs-distro-referenceapplication
$ cd openmrs-distro-referenceapplication
$ docker compose up

Then open http://localhost/openmrs/spa and log in with the demo credentials below.

Going to production

The same images, a few more decisions.

The Docker setup you tried on a laptop is the one you deploy. Before patients' records go in, four things need to be true.

Deploy-to-production guide →

  1. 01

    HTTPS at the gateway

    Terminate TLS in front of the gateway container. Never serve a real deployment over plain HTTP.

  2. 02

    Backups you have restored

    Nightly database dumps, kept off the server, and a restore you have actually rehearsed.

  3. 03

    Changed credentials

    Replace the demo admin password and database passwords in your compose environment before go-live.

  4. 04

    A plan for upgrades

    O3 ships several times a year and the Platform gets monthly patches. Pin a version, test the next one on a copy, then move.
